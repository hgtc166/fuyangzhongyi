Metabolic Clinic · Overview

代谢疾病门诊 · 概述

代谢性疾病以机体物质代谢紊乱为共同病理基础，广义上涵盖糖、脂、嘌呤、尿酸等代谢异常，并包括代谢相关性肿瘤。扶阳学术视其本为「阳气虚馁、运化失司」，以温补脾肾、运转枢机、次第递进为辨治纲领。

广义代谢疾病 · 疾病概述

代谢性疾病涉及糖、脂、蛋白质、嘌呤及尿酸等物质的合成、转运与利用失衡，涵盖糖尿病及其并发症、代谢相关脂肪性肝病、痛风、高尿酸血症、血脂异常、中心性肥胖等。此类疾病往往相互交织、共病发生——胰岛素抵抗、肥胖、血脂异常、高尿酸与高血压相互影响，共同构成「代谢综合征」的病理网络。据清单：痛风已成我国仅次于糖尿病的第二大代谢性疾病，且长期高尿酸血症「显著增加心血管疾病及代谢综合征的风险」。

扶阳学术视代谢异常为「阳气虚馁、运化失司」：脾阳不运则水谷不化、痰湿内生；命门火衰则膏脂堆积、清浊不分。故调理重在温补脾肾之阳、运转枢机，助一身气化，而非专事清泄。广义代谢疾病亦包括代谢相关性肿瘤——扶阳以「阳虚为本、阴实为标」认识其发生发展（详见模块一）。

以唐农教授「体、相、用」健康标准观之：体=精至、相=阴阳和、用=血气通调，为正常健康三要素。代谢病与肿瘤之辨治，皆本于此，并立足于「内阳外阴」本体结构——病在阳者扶阳抑阴，病在阴者用阳化阴。

模块一

中医辨证论治纲领 · 次第治疗

扶阳代谢病与肿瘤的辨治，以「体、相、用」健康标准与「内阳外阴」本体结构为根基，临证采唐农教授「次第治疗」三步法，由标及本、层层递进。

一

桂枝法

温通中上焦，「去其血脉」，开太阳、畅气机，为次第之始，先通阳道。

二

四逆法

温固下焦，回阳救逆、暖命门，使坎中一阳得固，阴寒得散。

三

培土填精

补中益气汤 / 附子理中丸 / 肾气丸，培元固本、先后天互资，为收功之法。

糖尿病肾脏疾病 龚胜男 / 唐农

病机：肾阳虚弱、火不暖土，内阳外阴本体结构偏离。

治则：温化内寒、健运脾土。

临床次第：桂枝法 → 桂附法 → 附子理中丸 / 肾气丸健脾填精。

文献病案：79 岁女性糖尿病肾病，经扶阳次第调理后尿蛋白转阴。

扶阳抗肿瘤 4 篇文献

总则：阳虚为本、阴实为标。肺癌「阳虚为本、阳化气阴成形」；肝癌「阳虚为本、痰瘀浊邪为标」；大肠癌「阳虚为本、阴实为标」；乳腺癌「扶阳温通、通调中焦、培土填精」为终极目标。

临床次第：桂枝法 → 四逆法 → 补中益气汤。

循证（肺癌 Meta）：温阳复方联合化疗较单纯化疗近期疗效更优（OR=2.19, P=0.0003），中重度骨髓抑制更少（OR=0.15, P<0.00001），胃肠反应更少（OR=0.41, P=0.002）。

文献病案：肝癌 70 岁男两年肿瘤未增大；大肠癌 59 岁直肠腺癌便隐血转阴；乳腺癌 42 岁女化疗后白细胞下降获助。

模块二

合并病 / 共病

代谢病组分常互为因果、共病发生；代谢异常又与肿瘤、睡眠、男科相互累叠。

代谢综合征组分互结 胰岛素抵抗、肥胖、血脂异常、高尿酸、高血压 糖尿病 ↔ 并发症 我国 2 型糖尿病合并慢性肾脏病约 36%；并见糖尿病足部溃疡 痛风 ↔ 心血管病 长期高尿酸显著增加心血管疾病及代谢综合征风险 肿瘤与代谢共病 肥胖 / 糖尿病为多种肿瘤危险因素；化疗伤阳耗气，与代谢病互累 睡眠 / 男科共病 与本馆睡眠障碍、男科康复门诊同根阳气虚馁，可协同调治

扶阳以「温补脾肾之阳、运转枢机」为纲，正可于代谢综合征多组分互结、肿瘤与代谢互累之时，标本兼顾、减毒增效。

模块三

就诊指引与注意事项

以下指引结合扶阳辨治特点与规范诊疗原则。

1

就诊前准备

携带近期化验（血糖 / 糖化血红蛋白 / 肝肾功能 / 尿酸 / 血脂）、影像与病理报告（肿瘤患者）、完整用药清单，便于综合评估。

2

辨证评估

依「体、相、用」与「内阳外阴」本体结构辨阴阳虚实、定次第；重舌脉与阳气盛衰，明辨病在阳或病在阴。

3

治疗原则

扶阳以温补脾肾、运转枢机为纲，次第递进（桂枝法 → 四逆法 → 培土填精）；不与规范西医治疗（降糖、化疗等）相斥，重在减毒增效、护阳固本。

4

生活调摄

饮食有节（忌生冷肥甘）、起居有常、适度运动以助气化；扶阳强调「温养阳气、忌戕伐」，避寒就温、固护命门。

5

复诊注意

慢病需长期随访（血糖 / 肾功能 / 尿酸监测）；肿瘤患者配合现代医学随访；中药随证更方，不可久服一方。
